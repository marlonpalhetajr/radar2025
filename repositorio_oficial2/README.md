# Radar Fapespa 2025 - Repositório de Arquivos

Repositório interativo de dados do Radar de Indicadores das Regiões de Integração.

## Estrutura
- `index.html` - página inicial com as 9 temáticas principais
- `dados.html` - página de dados interativa por temática
- `functions.js` - funções de carregamento, filtro e exportação
- `dados_repositorio/manifest.json` - manifesto com os CSVs do Radar

## Temáticas
- Demografia
- Educação
- Saúde
- Mercado de Trabalho
- Segurança
- Meio Ambiente
- Economia
- Finanças Públicas
- Infraestrutura

## Observação
Os CSVs são carregados a partir da pasta `CSV Radar em atualização` na raiz do projeto.
